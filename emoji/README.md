# emoji

Ten emoji picture packs. Each is ONE zip of PNG files (72x72, full colour), named after the Unicode
code points of the emoji, e.g. `1F600.png`, `1F44B-1F3FD.png` (waving hand, medium skin tone).
The Kurd Pad app downloads ONE zip only when the user picks that emoji style, and unpacks it in its private storage.
