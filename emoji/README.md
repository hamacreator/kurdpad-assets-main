# emoji

`openmoji-72x72-color.zip` - the OpenMoji emoji pictures (4495 PNG files, 72x72, full colour).
Each file is named after the Unicode code points of the emoji, e.g. `1F600.png`,
`1F44B-1F3FD.png` (waving hand, medium skin tone).

The Kurd Pad app downloads this ONE zip only when the user picks the "OpenMoji" emoji style,
and unpacks it in its private storage.
